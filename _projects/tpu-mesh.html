Results

A mesh is a stack of concentric rings around a hub, closed by a flange. The base contour is a circle, a slot or a rounded rectangle. Every ring is a scaled copy of it: $C_i(t) = r_i\,C(t)$, $r_i = i\,w$, with $w$ the ring width and $t\in[0,1)$ the perimeter parameter. Dashed and solid rings alternate in a user-defined pattern ($n_{dash}$ dashed, then $n_{solid}$ solid). For the slot and rounded rectangle the rings are homothetic, not offset curves, so the radial ring width is not uniform.

{% include figure.html src="assets/img/kirigamiexample.png" alt="Kirigami disc configurator, 2D preview" caption="Anatomy of a generated disc in the configurator: hub, dashed rings, solid ring, flange, opening (red) and handles (green)." %}

Each dashed ring is cut into $N$ dashes. With $d_i$ the solid fraction (duty) of ring $i$, dash $k$ spans $t\in\left[\varphi_i + \tfrac{k}{N} + \tfrac{1-d_i}{2N},\; \varphi_i + \tfrac{k}{N} + \tfrac{1+d_i}{2N}\right]$. The phase $\varphi_i = \tfrac{1}{2N}\left(\lfloor i/2 \rfloor \bmod 2\right)$ shifts every second pair of rings by half a period, so slits are staggered like bricks. That stagger is what makes it kirigami: the ligaments between slits bend and the disc opens out of plane.

Duty varies linearly from the inner to the outer dashed ring: $d_i = d_{in} + (d_{out}-d_{in})\,\dfrac{i-n_h}{n_b-n_h-1}$, with $n_h$ hub rings and $n_b$ body rings. On a circle, dash and gap lengths are $s_i = 2\pi r_i d_i / N$ and $g_i = 2\pi r_i (1-d_i)/N$. Linear $d_i$ does not keep $s_i$ constant. $d_i \propto 1/r_i$ would; it is the natural next step.

The part is a two-level height field. Hub, thick flange sectors and handles are extruded to $h_{struct}$; rings to $h_{ring}$, thinner so they flex. The slice view cuts this field at a height $z$, so you can check what a given print layer contains.

The flange follows the same dash pattern: thick ($h_{struct}$) on a dash, thinned ($h_{ring}$) in the gaps, set by a flange duty $d_f$. At $d_f = 1$ it is one continuous thick ring. Handles are anchored on it, so $d_f$ decides whether a handle sits on a continuous ring or on isolated thick segments.

A handle is a quadratic Bézier arc between two anchors $A$ and $B$ on the flange, a chosen span apart. Control point: $Q = M + \tfrac{h(1+\kappa)}{2}\,\hat n$, with $M$ the chord midpoint, $\hat n$ the outward normal, $h$ the height parameter and $\kappa$ the curvature. Curve: $\mathbf{B}(\tau) = (1-\tau)^2 A + 2\tau(1-\tau)\,Q + \tau^2 B$. The arc is thickened by $\pm w_h/2$ and extruded to $h_{struct}$. Its apex sits at $\tfrac{h(1+\kappa)}{4}$ from the chord, so the loop reaches height $h$ only for $\kappa = 3$.

An optional opening removes an angular sector $\theta$, centred at a chosen angle, over a chosen range of rings. Dashes are clipped against the sector and solid rings are split, leaving a gap through the mesh.

def dash_intervals(n_seg, duty, phase):
    seg = 1/n_seg; sol = seg*duty; gap = seg*(1-duty)
    return [(phase + k*seg + gap/2, phase + k*seg + gap/2 + sol)
            for k in range(n_seg)]

def flange_sectors(n_seg, duty, phase):
    # thick on the dashes, thinned in the gaps; duty>=1 -> one thick ring
    if duty >= 0.999: return [(0.0, 1.0, True)]
    iv = dash_intervals(n_seg, duty, phase)
    gaps = [(iv[k][1], iv[k+1][0] if k+1 < n_seg else iv[0][0]+1.0, False)
            for k in range(n_seg)]
    return [(a, b, True) for a, b in iv] + gaps
